# 拾光笺 v0.2.0 · 开发与验证记录

日期：2026-10-25。包名仍为 `cn.ray.daybook`，versionCode 提升为 2。Android 8.0 / API 26 起可用。

## 本次调整

- 应用名由「日有记」改为「拾光笺」。桌面名称、顶部标题、设置、备份文件名前缀与错误提示同步更新。
- 首页题签由「一日一记」改为「日常拾记」，副文案为「随手记下，皆是光阴。」；记录数量与日期都不作每日配额要求。
- 新增默认首页「全部」，底部导航为：全部 / 按日 / 日历 / 设置。
- 全部事项按所属日期分组，组内按事项时间倒序；默认展示最近 50 条，点击「加载更早的记录」继续查看。回收站内容不混入普通列表。
- 点击日期分组可进入按日页面；详情返回后恢复列表位置。新建记录在全部入口默认今天，保存后回到全部列表顶部。
- 按日和日历继续支持补记历史日期；原有图文、草稿、搜索、回收站、备份和恢复功能保留。

## 兼容性

包名、开发签名、数据库结构和数据库版本保持兼容。已比较 v0.1 源码归档与当前 Room schema 的 identityHash，一致；无需新建数据库或清空数据。

备份格式仍为 1，继续读取原 `.daybook` 备份。appVersion 只用于描述导出应用版本，不作为格式是否可读的判断条件。

同一开发签名的 v0.2 APK 可覆盖 v0.1 测试版；覆盖安装与系统/厂商相关行为尚未在真实手机上执行。正式发布依旧需要项目所有者保管的发布签名。

构建命令包含 assembleDebug、testDebugUnitTest、verifyOfflineManifest、lintDebug、assembleDebugAndroidTest、assembleRelease。Debug 与经过 R8 的 Release 均完成构建。

UI 和 Repository 测试运行在本地 Robolectric Android API 28 环境。界面截图为实际 Compose 页面绘制，数据由测试用例生成；不是手机实拍或完整模拟器截屏。真实设备的触控、文件选择器、系统备份与性能验收仍按 v0.1 记录的边界执行。

Lint 没有错误；保留的三个非阻断建议与 v0.1 相同。APK 签名、包名和无网络权限检查单独执行。

UI 仪器测试会清空测试应用数据库，请只在专用设备运行，不用于存有真实日记的手机。
