# 日有记 v0.1.0 · 开发与验证记录

日期：2026-10-25。包名：`cn.ray.daybook`。最低 Android 8.0 / API 26，编译与目标 API 35。

## 实际交付

- 原生 Kotlin / Compose 源码、Room schema、Gradle Wrapper、锁定的依赖目录和 PowerShell 构建入口。
- `dist/daybook-0.1.0-debug.apk`：可安装、带 Android 开发签名的测试版。
- `dist/daybook-0.1.0-source.zip`：源码归档，排除本机 SDK/JDK、缓存、构建中间文件、local.properties 和密钥。
- `dist/SHA256SUMS.txt`：交付文件摘要。
- `docs/screenshots/timeline.png`：本地 Android 运行时绘制的时间轴界面，内容是自动测试生成的样例。

另外通过 `assembleRelease` 生成了启用 R8 的未签名发布包，位于 app/build/outputs/apk/release；未签名包不能直接安装，不作为本次用户测试入口。正式发布签名仍需项目所有者提供与保管。

## 构建与静态验证

使用 Microsoft JDK 17、Gradle 8.11.1、AGP 8.9.2、Kotlin 2.1.20、Android SDK 35。

执行并通过：

```text
assembleDebug
testDebugUnitTest
verifyOfflineManifest
lintDebug
assembleDebugAndroidTest
assembleRelease
```

APK 的 Android v2 签名由 apksigner 验证通过。使用 aapt 分别读取 Debug 与 Release APK 权限，两者均不含 INTERNET、全部文件管理、相册全库、定位或联系人权限；仅含 AndroidX 内部动态广播接收器使用的同包名签名权限。

Lint：0 个错误，3 个非阻断建议。两项建议涉及按可用磁盘空间进行保守估算而非自动回收其他应用缓存；一项建议用 KTX 包装 Bitmap 缩放。未禁用这些检查，也未使用基线隐藏问题。

5. 损坏备份拒绝恢复，现有正文不改变。
6. 使用磁盘数据库写入正式记录与草稿，关闭数据库并重新打开，日期、时间和正文完整保留。

## 设备验证边界

已经构建真实设备可运行的仪器测试包，共用相同的数据库/备份测试与界面行为测试。设备测试入口为 `connectedDebugAndroidTest`。

本机缺少 Android Emulator hypervisor driver。尝试无窗口软件模式的 API 35 AOSP 模拟器后，设备持续处于 offline，未能完成启动，已停止该测试设备以释放资源。因此没有把真机/完整模拟器仪器测试计入“通过”。

还需在真实手机上验收：厂商文件选择器的本地筛选、图片捏合与翻页、深浅色系统栏、系统字号、跨进程强制结束后的草稿恢复、低存储空间和厂商系统备份排除行为。文档中的性能目标尚未在基准真机测量。

## 与方案的实现细节

- 首版页面使用 ViewModel 显式页面状态导航，保存所选日期与草稿 ID；未引入独立导航库。
- 图片资源 ID 使用内容 SHA-256，允许不同事项复用同一图片；正式事项及草稿 ID 使用 UUID。
- 备份关系内嵌于 JSONL 对象的有序 assets 数组，省去一份重复的关系文件。
- 缩略图属于可丢弃缓存；缓存不存在时图片加载器会按显示尺寸从私有原片解码，完整记录不依赖缓存。
- 首版不做加密，备份包包含原片及原片已有元信息；数据管理页面已明确说明。
