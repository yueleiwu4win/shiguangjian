# 离线事记 App · 初版需求 v0.1（古风时间轴修订）

日期：2026-10-25。暂定产品名「日有记」。本文是供讨论的产品方案，尚非已实现的安卓应用。

## 1. 产品定位

面向个人的离线生活记录工具：以天为目录，以事项为单位，随时记下一段文字或几张图片，之后能按日期或关键词找回来。

核心目标：随手记、容易找、数据留在自己手中。默认不登录、不联网、不做社交。不将每天记录作为必须完成的任务，不做连续打卡压力设计。

假设：单人、单设备优先；“事项”表示发生过的事情，不默认带待办或完成状态。

## 2. 核心使用场景

1. 随手记：今天散步拍了照片，打开 App，新建事项，输入一句话并附图。
2. 一天多记：早上记工作，下午记生活，每件事独立成条，归属于同一天。
3. 补记：选择昨天或更早的日期，补充遗漏的事情。
4. 回看：从日历定位某天，查看当天所有事项和图片。
5. 找事情：忘了具体日期，通过文字关键词查找，再进入详情。
6. 保存与迁移：手动导出包含正文与图片的备份，日后恢复到本机或另一台设备。

## 3. 首版范围

| 模块 | 初版要求 | 主要规则 |
| --- | --- | --- |
| 当天记录 | 默认打开今天，按时间显示事项列表 | 前一天、后一天、回到今天；空日期显示新增入口 |
| 新建 / 编辑 | 日期、时间、可选标题、正文、多张图片 | 标题可省略；正文与图片至少有一项；默认使用当前查看日期 |
| 图片 | 本地相册选择、缩略图、移除、大图查看 | 建议先限制每条 9 张；缩略图裁切不改变完整图片；暂不做图片编辑 |
| 日历查询 | 月历、切月、日期选择 | 有记录日期显示数量；选定日期后显示当天事项，可补记 |
| 事项详情 | 查看完整正文和图片，进入编辑 | 返回时保留来源页面、日期及搜索条件 |
| 本地搜索 | 搜索标题与正文，按时间倒序显示 | 支持日期范围；不搜索图片里的文字；结果展示事项所属日期 |
| 草稿 | 写作过程自动保存本机草稿 | 返回时保留草稿；再次进入可继续；保存成功后清除对应草稿 |
| 删除与回收站 | 删除后可恢复，手动永久删除 | 删除正文和图片作为整体；永久删除或清空回收站前确认 |
| 备份与恢复 | 手动导出、选择文件恢复 | 包含文字、图片、关联信息和格式版本；展示最近成功备份时间 |
| 设置 | 字体大小、主题、数据管理 | 跟随系统外观为默认；展示记录数及占用空间 |

首版不加入账号、云同步、在线 AI、社区、广告、定位轨迹、视频、复杂富文本和任务管理。

## 4. 后续增强，暂不阻塞首版

- 标签：工作、生活、学习或用户自定义；为事项加标签并筛选。
- 收藏：标记重要记录，集中回看。
- 隐私锁：通过系统验证解锁 App；不能把“应用锁”误称为“内容加密”。
- 心情：可选，不强制每条或每天填写。
- 导出阅读副本：按月份导出图文文档，便于整理和打印。
- 本地提醒：用户主动开启后，在本机定时提醒记录。

## 5. 页面结构

底部三个入口：记录 / 日历 / 设置；搜索位于记录页右上角。

### 记录页

- 顶部：日期、前后一天、回到今天、搜索。
- 主区：左侧竖向时间轴串联当天所有事项，时间与节点对齐；右侧依次显示可选标题、正文、图片及更多操作。
- 时间轴只连接第一条至最后一条记录；只有一条记录时保留节点，不绘制无意义的长线。多条长短内容自然撑开，节点和线仍连续。
- 顶部为「一日一记」手记题签、简短副文案和朱砂印记，替代个人封面及头像展示。
- 主操作：右上角笔形图标及「记一笔」文字入口；空状态和草稿状态保留新增、继续草稿按钮。
- 空状态：「这一天还没有记录」及新增入口。
- 点击正文或更多按钮进入详情，点击图片直接查看大图；当天事项按事项时间从新到旧排列。
- 图文样式：1 张图较大展示；4 张图采用 2×2；其他数量采用每行 3 张，最多 9 张。缩略图裁切不改变原图片内容。

### 日历页

- 顶部：当前年月与月份切换，也可直接选择日期跳转。
- 中部：月历，以周一为每周第一天；今天、选中日期、有记录日期分别标识。
- 下方：选中日期的事项列表及新增入口。

### 新建 / 编辑页

- 顶部：返回、页面名称、保存。
- 内容顺序：正文 → 图片 → 所属日期与时间 → 可选标题，优先让用户直接开始记录。
- 新建时默认当前查看日期；查看历史日期时点击新增就是补记该日期。
- 图片区域：缩略图、移除、添加入口及数量提示。
- 未输入有效正文且没有图片时，保存不可用或提示补充内容。
- 退出编辑保留草稿；再次进入提示继续。保存失败时不清空输入。

### 详情页

- 展示所属日期、事项时间、完整标题 / 正文、图片。
- 点击图片进入大图，支持缩放和左右切换。
- 提供编辑和移入回收站。

### 搜索页

- 输入关键词，选填日期范围，展示匹配数量及结果。
- 结果包含事项日期、时间和匹配内容；点击进入详情。
- 无结果时允许清空日期范围或修改关键词。

### 设置与数据管理

- 备份 / 恢复、最近备份时间、数据占用、回收站、显示设置。
- 无登录、账户和联网状态入口。

## 6. 数据与关键规则

### 事项结构

| 字段 | 含义 |
| --- | --- |
| 唯一 ID | 用于图片关联、备份及恢复去重 |
| 所属日期 | 用户选定的日历日期，不随之后切换时区而改变 |
| 事项时间 | 用于当天排序，可修改 |
| 标题 | 可选；无标题时列表直接展示正文摘要或“图片记录” |
| 正文 | 纯文本，保留换行 |
| 图片列表 | App 内部图片引用和展示顺序 |
| 创建 / 修改时间 | 系统记录，不因为补记历史日期而伪装成历史创建时间 |
| 删除状态 | 记录是否处于回收站 |

### 内容与日期

- 一天允许多条记录，也允许没有记录。
- 初版作为事记工具，仅允许今天及以前的日期；不扩展为未来日程。
- 当天排序按事项时间降序，最新在前；时间相同按创建时间降序稳定排序。
- 跨日写作不自动改变该条事项的所属日期。
- 图片可单独成条；纯空格正文不算有效内容；仅填写标题不能保存空事项。

### 完全离线

- 安卓成品的记录、查看、搜索、备份、恢复均需在无网络环境完成。
- 应用不申请网络权限，不接入联网统计、广告或远程字体资源。
- 图片导入后存为 App 管理的副本；用户删除相册原图后，记录内图片仍可查看。
- 图片生成预览缩略图，列表不同时解码大量原图；保存策略需在开发阶段实测清晰度和空间。
- 只在选择图片时请求必要访问；拒绝图片访问仍可记录文字。
- 明确配置系统云备份策略，以兑现用户对“不联网、数据不自动上云”的预期。
- 本地保存不等于已加密；加密需求须单独设计与验证。

### 备份恢复

- 导出一个可迁移的备份包，包含事项、图片、图片关联及格式版本；读取和生成过程离线完成。
- 用户主动选择本机或外部存储位置；不是后台自动上传。
- 导出失败不能显示成功；上次成功时间只在完整文件写入成功后更新。
- 导入前检查版本、完整性、图片引用与可用空间，先展示可恢复记录数和冲突数。
- 初版默认合并导入：同 ID 且内容相同的跳过；同 ID 内容不同的保留两个版本，并明确标注恢复副本，避免静默覆盖。
- 恢复失败不得破坏已有数据；回收站与草稿也应有明确的备份字段。
- 设置页提示：卸载 App 或设备丢失可能导致本机内容丢失，应将备份保存到 App 数据之外。

## 7. 验收要点

1. 飞行模式下，可新建纯文字、纯图片、图文记录，编辑后重新打开内容完整。
2. 同一天可保存多条事项；补记历史日期后只出现在目标日期；跨月切换正确。
3. 删除相册原图后，已导入的图片仍可查看；重启 App 后文字与图片关联不丢失。
4. 拒绝图片权限、存储不足或保存中断时，显示明确结果，保留未保存内容。
5. 输入过程中返回或被系统终止后，能恢复最近成功落盘的草稿。
6. 搜索标题和正文能找到对应事项，并能返回原搜索结果。
7. 删除后进入回收站，恢复后回到原日期；永久删除前确认。
8. 导出后在空数据库恢复，记录数、正文、图片与关联一致；重复导入不重复生成相同记录。
9. 损坏备份不能覆盖现有数据；没有备份成功时不显示“已备份”。
10. 字体放大后主要按钮和正文可读，图片缩略图不挤压操作区域。

## 8. 本次原型边界

本次为交互讨论原型，展示记录、月历、编辑、详情、搜索，以及图片添加位置。使用示例数据与示例图片占位；可模拟新增、修改、删除与撤销。没有生成 APK；未接入真实本机数据库、相册、持久草稿、回收站、备份或恢复。刷新后示例记录重置，不应用来存放真实日记。

## 9. 可继续确认的产品偏好

- 主要用于生活、工作，还是两者混合？决定是否把标签提前到首版。
- 是否涉及私密内容？决定隐私锁和加密是否提升优先级。
- 图片以看清内容为主，还是必须保留原片？决定空间与图片存储策略。

这些问题不影响先用当前方案确认核心流程。

## 10. 当前视觉方向：古风手记与竖向时间轴

在朋友圈式图文阅读基础上，按用户新反馈改为左侧竖向时间轴：左侧显示准确的 24 小时时间与清晨、午后等辅助提示，细线串联各条事项，右侧保留正文和图片。最新记录在上方，搜索和日历下的结果也使用相同结构；跨日期搜索结果另标所属日期。

视觉采用宣纸暖色、墨色正文、淡褐轴线和朱砂操作色；题签及可选事项标题用本机楷体或宋体回退，正文维持清晰、可放大的字体。深色模式跟随系统适配。古风主要用于字体、色彩、印记和留白，不改变日期、保存、搜索等操作的含义。

产品仍为个人离线事记，保留按天查询，无好友、点赞、评论或公开发布功能。图片仍为示例占位。界面中的“仅自己可见”表示产品定位，并非已完成内容加密。
